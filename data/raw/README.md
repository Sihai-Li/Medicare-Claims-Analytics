# Raw CMS data

Place the downloaded CMS Synthetic Medicare Claims files in this directory.
The profiling script reads pipe-delimited CSV files directly and inspects ZIP
archives for integrity.

Expected source:
https://data.cms.gov/collection/synthetic-medicare-enrollment-fee-for-service-claims-and-prescription-drug-event

Raw files are excluded from Git because they are large and can be downloaded
again from CMS. Do not modify the source files in place.
